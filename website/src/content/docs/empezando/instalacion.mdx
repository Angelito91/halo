Halo se distribuye como un único binario llamado `halo`. Todavía no hay un
paquete en crates.io, así que la vía principal es compilar desde el código
fuente.

## Requisitos

| Componente | Versión | ¿Para qué? |
|---|---|---|
| Rust + Cargo | Estable reciente (edición 2021) | Compilar el proyecto |
| Git | Cualquiera reciente | Clonar el repositorio |

No necesitas LLVM, Clang, un compilador de C ni ninguna biblioteca del
sistema. Halo es un intérprete escrito en Rust puro y no tiene dependencias
externas.

Si aún no tienes Rust, instálalo con [rustup](https://rustup.rs/):

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

En Windows, descarga el instalador de rustup desde [rustup.rs](https://rustup.rs/).

## Compilar desde fuente

<Tabs>
	<TabItem label="Linux / macOS">
		```bash
		git clone https://github.com/Angelito91/halo.git
		cd halo
		cargo build --release
		```

		El binario queda en `target/release/halo`.
	</TabItem>

	<TabItem label="Windows">
		```powershell
		git clone https://github.com/Angelito91/halo.git
		cd halo
		cargo build --release
		```

		El binario queda en `target\release\halo.exe`.
	</TabItem>
</Tabs>

También puedes instalarlo en tu `PATH` de Cargo:

```bash
cargo install --path . --locked
```

Esto coloca `halo` en `~/.cargo/bin` (o `%USERPROFILE%\.cargo\bin` en
Windows), que normalmente ya está en el `PATH`.

## Verificar

```bash
halo version
# 🌟 Halo Programming Language v0.3.0

halo --help
```

Si el comando no se encuentra, usa la ruta completa:

```bash
./target/release/halo version
```

## Primer contacto

Crea un archivo `hola.halo`:

```halo
print("Hello, Halo!")
```

Ejecútalo con el intérprete:

```bash
halo run hola.halo
# Hello, Halo!
```

También puedes inspeccionar las fases del programa:

```bash
halo tokens hola.halo
halo ast hola.halo
```

## Problemas frecuentes

### `cargo: command not found`

Rust no está instalado o `~/.cargo/bin` no está en el `PATH`. Instala Rust con
rustup y abre una terminal nueva.

### `halo: command not found`

Si compilaste sin `cargo install`, el binario está en `target/release/halo`.
Usa la ruta completa o añade esa carpeta al `PATH`:

```bash
export PATH="$PWD/target/release:$PATH"
```

### La primera compilación tarda

Cargo compila el proyecto y genera el binario la primera vez. Las siguientes
compilaciones reutilizan la caché y son mucho más rápidas.

### Error de permisos al ejecutar

En Linux o macOS, comprueba que el binario tenga permiso de ejecución:

```bash
chmod +x target/release/halo
```

## Actualizar

```bash
git pull
cargo build --release
```

Si instalaste con `cargo install --path .`, vuelve a ejecutarlo para
reemplazar el binario:

```bash
cargo install --path . --locked
```

## Desinstalar

Si usaste `cargo install`:

```bash
cargo uninstall halo
```

Si compilaste en el repositorio, basta con borrar la carpeta `target/`.
