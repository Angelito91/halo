Halo se distribuye como un único binario llamado `halo`. Puedes descargar un
binario precompilado para tu plataforma o compilarlo desde el código fuente.
Todavía no hay un paquete en crates.io.

## Descargar un binario

Cada release publica binarios nativos para estas plataformas:

| Plataforma | Archivo |
|---|---|
| Linux x86_64 (estático) | `halo-x86_64-unknown-linux-musl.tar.gz` |
| Linux ARM64 (estático) | `halo-aarch64-unknown-linux-musl.tar.gz` |
| macOS Apple Silicon | `halo-aarch64-apple-darwin.tar.gz` |
| macOS Intel | `halo-x86_64-apple-darwin.tar.gz` |
| Windows x86_64 | `halo-x86_64-pc-windows-msvc.zip` |
| Windows ARM64 | `halo-aarch64-pc-windows-msvc.zip` |

Descárgalos desde la página de [Releases](https://github.com/Angelito91/halo/releases).

<Tabs>
	<TabItem label="Linux x86_64">
		```bash
		curl -LO https://github.com/Angelito91/halo/releases/download/v0.3.0/halo-x86_64-unknown-linux-musl.tar.gz
		tar -xzf halo-x86_64-unknown-linux-musl.tar.gz
		sudo install -m 755 halo-x86_64-unknown-linux-musl/halo /usr/local/bin/halo
		```
	</TabItem>

	<TabItem label="macOS Apple Silicon">
		```bash
		curl -LO https://github.com/Angelito91/halo/releases/download/v0.3.0/halo-aarch64-apple-darwin.tar.gz
		tar -xzf halo-aarch64-apple-darwin.tar.gz
		sudo install -m 755 halo-aarch64-apple-darwin/halo /usr/local/bin/halo
		```
	</TabItem>

	<TabItem label="Windows x86_64">
		```powershell
		Invoke-WebRequest `
		  https://github.com/Angelito91/halo/releases/download/v0.3.0/halo-x86_64-pc-windows-msvc.zip `
		  -OutFile halo.zip
		Expand-Archive halo.zip -DestinationPath .
		.\halo-x86_64-pc-windows-msvc\halo.exe version
		```
	</TabItem>
</Tabs>

### Verificar la descarga

Cada release incluye un archivo `SHA256SUMS`:

```bash
sha256sum -c SHA256SUMS
# macOS: shasum -a 256 -c SHA256SUMS
```

Los binarios también incluyen una attestation de build de GitHub. Si tienes
[GitHub CLI](https://cli.github.com/):

```bash
gh attestation verify halo-x86_64-unknown-linux-musl.tar.gz \
  --repo Angelito91/halo
```

## Compilar desde fuente

### Requisitos

| Componente | Versión | ¿Para qué? |
|---|---|---|
| Rust + Cargo | Estable reciente (edición 2021) | Compilar el proyecto |
| Git | Cualquiera reciente | Clonar el repositorio |

No necesitas LLVM, Clang ni bibliotecas adicionales del proyecto. Halo es un
intérprete escrito en Rust puro y no tiene dependencias externas; el toolchain
de Rust se encarga de compilar y enlazar.

Si aún no tienes Rust, instálalo con [rustup](https://rustup.rs/):

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

En Windows, descarga el instalador de rustup desde [rustup.rs](https://rustup.rs/).

### Compilación

<Tabs>
	<TabItem label="Linux / macOS">
		```bash
		git clone https://github.com/Angelito91/halo.git
		cd halo
		cargo build --release
		```

		El binario queda en `target/release/halo`.
	</TabItem>

	<TabItem label="Windows">
		```powershell
		git clone https://github.com/Angelito91/halo.git
		cd halo
		cargo build --release
		```

		El binario queda en `target\release\halo.exe`.
	</TabItem>
</Tabs>

También puedes instalarlo en tu `PATH` de Cargo:

```bash
cargo install --path . --locked
```

Esto coloca `halo` en `~/.cargo/bin` (o `%USERPROFILE%\.cargo\bin` en
Windows), que normalmente ya está en el `PATH`.

## Verificar

```bash
halo version
# 🌟 Halo Programming Language v0.3.0

halo --help
```

Si el comando no se encuentra, usa la ruta completa:

```bash
./target/release/halo version
```

## Primer contacto

Crea un archivo `hola.halo`:

```halo
print("Hello, Halo!")
```

Ejecútalo con el intérprete:

```bash
halo run hola.halo
# Hello, Halo!
```

También puedes inspeccionar las fases del programa:

```bash
halo tokens hola.halo
halo ast hola.halo
```

## Problemas frecuentes

### `cargo: command not found`

Rust no está instalado o `~/.cargo/bin` no está en el `PATH`. Instala Rust con
rustup y abre una terminal nueva.

### `halo: command not found`

Si compilaste sin `cargo install`, el binario está en `target/release/halo`.
Usa la ruta completa o añade esa carpeta al `PATH`:

```bash
export PATH="$PWD/target/release:$PATH"
```

### La primera compilación tarda

Cargo compila el proyecto y genera el binario la primera vez. Las siguientes
compilaciones reutilizan la caché y son mucho más rápidas.

### Error de permisos al ejecutar

En Linux o macOS, comprueba que el binario tenga permiso de ejecución:

```bash
chmod +x target/release/halo
```

## Actualizar

```bash
git pull
cargo build --release
```

Si instalaste con `cargo install --path .`, vuelve a ejecutarlo para
reemplazar el binario:

```bash
cargo install --path . --locked
```

## Desinstalar

Si usaste `cargo install`:

```bash
cargo uninstall halo
```

Si compilaste en el repositorio, basta con borrar la carpeta `target/`.
