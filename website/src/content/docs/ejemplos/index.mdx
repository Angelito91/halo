El repositorio incluye una colección de programas comentados en `examples/`.
Son la forma más rápida de ver el lenguaje en acción y de comprobar que tu
instalación funciona.

```bash
git clone https://github.com/Angelito91/halo.git
cd halo

halo run examples/01_hello.halo
halo run examples/03_factorial.halo
```

## Cómo leer un ejemplo

1. Abre el archivo y lee los comentarios de sección.
2. Ejecútalo con `halo run`.
3. Cambia algún valor y vuelve a ejecutarlo.
4. Usa `halo ast` para ver cómo se representa.
5. Usa `halo tokens` si quieres ver cómo el lexer parte el texto.

```bash
halo run examples/05_operators.halo
halo ast examples/05_operators.halo
halo tokens examples/05_operators.halo
```
