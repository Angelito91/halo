## Empieza en un par de minutos

Halo está escrito en Rust y no tiene dependencias externas. Solo necesitas un
toolchain estable de Rust.

<Tabs>
	<TabItem label="Linux / macOS">
		```bash
		git clone https://github.com/Angelito91/halo.git
		cd halo
		cargo build --release
		./target/release/halo examples/01_hello.halo
		```
	</TabItem>
	<TabItem label="Windows">
		```powershell
		git clone https://github.com/Angelito91/halo.git
		cd halo
		cargo build --release
		.\target\release\halo.exe examples\01_hello.halo
		```
	</TabItem>
</Tabs>

¿Prefieres los detalles? Sigue la [guía de instalación](empezando/instalacion/)
o salta directamente al [primer programa](empezando/primer-programa/).

## Todo el pipeline, a la vista

Puedes inspeccionar cada fase del intérprete con un solo ejecutable.

<CardGrid>
	<Card title="Lexer" icon="pencil">
		Convierte el texto en tokens con posición. Míralos con `halo tokens`.
	</Card>
	<Card title="Parser" icon="approve-check">
		Construye un AST legible. Imprímelo con `halo ast`.
	</Card>
	<Card title="Intérprete" icon="rocket">
		Ejecuta el AST directamente con `halo run`.
	</Card>
	<Card title="Errores claros" icon="error">
		Variables, aridad, overflow, recursión y bucles infinitos se detectan con
		posición.
	</Card>
</CardGrid>

## Código que se lee como pseudocódigo

Sin `main`, sin tipos obligatorios y sin llaves en líneas separadas:

```halo
// Factorial recursivo
factorial(n) {
    if n <= 1 { return 1 }
    return n * factorial(n - 1)
}

print(factorial(10))   // 3628800
```

```text
$ halo run factorial.halo
3628800
```

Pensado para **programas cortos y scripts**: automatizar tareas, convertir
datos o practicar algoritmos. No necesitas montar un proyecto ni aprender un
ecosistema entero.

## Un solo motor

Desde la versión 0.3.0, Halo es **interpreter-only**:

```text
archivo.halo → lexer → tokens → parser → AST → evaluador → stdout
```

No hay backend nativo, VM ni artefactos que compilar. El proyecto se mantiene
pequeño y el comportamiento documentado es el que ves al ejecutar `halo run`.

| Pieza | Qué hace |
|---|---|
| Lexer | Texto → tokens con posición |
| Parser | Tokens → AST |
| Evaluador | Ejecuta el AST |
| Stdlib | Built-ins y métodos |
| CLI | `run`, `check`, `tokens` y `ast` |
