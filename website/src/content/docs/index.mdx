## Empieza en un par de minutos

Halo está escrito en Rust y no tiene dependencias externas. Solo necesitas un
toolchain de Rust estable: no hay LLVM, Clang ni bibliotecas del sistema que
instalar.

<Tabs>
	<TabItem label="Linux / macOS">
		```bash
		git clone https://github.com/Angelito91/halo.git
		cd halo
		cargo build --release
		./target/release/halo examples/01_hello.halo
		```
	</TabItem>
	<TabItem label="Windows">
		```powershell
		git clone https://github.com/Angelito91/halo.git
		cd halo
		cargo build --release
		.\target\release\halo.exe examples\01_hello.halo
		```
	</TabItem>
</Tabs>

¿Prefieres los detalles? Sigue la [guía de instalación](empezando/instalacion/)
o salta directamente al [primer programa](empezando/primer-programa/).

## Todo el pipeline, a la vista

Halo no esconde las fases: puedes inspeccionar los tokens, el AST y la
evaluación con un solo ejecutable.

<CardGrid>
	<Card title="Lexer" icon="pencil">
		Escaneo lineal que convierte el texto en tokens con su posición exacta.
		Míralos con `halo tokens`.
	</Card>
	<Card title="Parser" icon="approve-check">
		Parser recursivo descendente que construye un AST legible. Imprímelo con
		`halo ast`.
	</Card>
	<Card title="Intérprete" icon="rocket">
		Evaluador tree-walking que ejecuta el AST directamente con `halo run`.
		Sin binarios intermedios ni pasos ocultos.
	</Card>
	<Card title="Errores claros" icon="error">
		Variables inexistentes, aridad incorrecta, overflow, recursión excesiva y
		bucles infinitos se detectan con mensajes y posición.
	</Card>
</CardGrid>

## Código que se lee como pseudocódigo

Sin `main`, sin tipos obligatorios y sin llaves en líneas separadas:

```halo
// Factorial recursivo
factorial(n) {
    if n <= 1 { return 1 }
    return n * factorial(n - 1)
}

print(factorial(10))   // 3628800
```

```text
$ halo run factorial.halo
3628800
```

Es un lenguaje pensado para **programas cortos y scripts**: automatizar una
tarea, convertir datos, practicar un algoritmo o enseñar cómo se evalúa una
expresión. No necesitas montar un proyecto ni aprender un ecosistema entero
antes de escribir tu primera línea.

## Un solo motor

Halo es **interpreter-only** desde la versión 0.3.0. El flujo es siempre el
mismo:

```text
archivo.halo → lexer → tokens → parser → AST → evaluador → stdout
```

No hay backend nativo, ni máquina virtual, ni artefactos que compilar. Esa
decisión mantiene el proyecto pequeño y hace que el comportamiento documentado
sea exactamente el que ves al ejecutar `halo run`.

| Pieza | Qué hace |
|---|---|
| Lexer | Texto → tokens con línea y columna |
| Parser | Tokens → AST |
| Evaluador | Recorre el AST y ejecuta el programa |
| Stdlib | Built-ins y métodos sobre valores ya evaluados |
| CLI | `run`, `check`, `tokens` y `ast` en un único binario |
